# Web dashboard

Vanilla HTML, CSS and JavaScript in `src/`. No frontend framework or client-side database.

Run `npm run dev` from the project root for the MongoDB-backed app, or `npm run build:web` to generate the optional private-preview Worker. See the root README for setup and deployment.

The private-preview identity is local-only in `.openai/hosting.json`. A clean checkout builds with `.openai/hosting.example.json`. Do not commit credentials or live phone activity.
